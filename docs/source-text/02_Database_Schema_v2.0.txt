OMNI CRM – DATABASE SCHEMA v2.0
Phạm vi: CRM Core + Sales + Omnichannel + Chatbot + AI + Knowledge Hub + Automation + AuditDatabase đề xuất: PostgreSQLMục đích: Làm đặc tả dữ liệu chính thức để Claude triển khai migration, ORM model, API và service layer.

1. MỤC TIÊU THIẾT KẾ
Database của Omni CRM phải đáp ứng đồng thời:
Quản lý khách hàng và danh bạ.
Quản lý Lead.
Quản lý hoạt động tiếp xúc.
Quản lý bán hàng.
Quản lý Opportunity/Pipeline.
Quản lý báo giá.
Quản lý hợp đồng.
Quản lý thanh toán.
Quản lý Task/Meeting.
Quản lý giao tiếp đa kênh.
Quản lý Chatbot.
Quản lý Human Handoff.
Quản lý AI Assistant.
Quản lý AI Insight.
Quản lý Knowledge Base/RAG.
Quản lý Workflow/Automation.
Quản lý Notification.
Quản lý Audit.
Hỗ trợ mở rộng SaaS/multi-tenant trong tương lai.

4. KIỂU KHÓA CHÍNH
Tất cả bảng nghiệp vụ sử dụng:
UUID

Khuyến nghị:
gen_random_uuid()

Không dùng integer auto-increment cho các entity chính.

5. TRƯỜNG AUDIT CHUNG
Hầu hết bảng nghiệp vụ phải có:
id UUID PRIMARY KEY

created_at TIMESTAMPTZ
created_by UUID NULL

updated_at TIMESTAMPTZ
updated_by UUID NULL

deleted_at TIMESTAMPTZ NULL
deleted_by UUID NULL

Nếu bảng chỉ mang tính liên kết thì có thể giản lược.

6. SOFT DELETE
Không xóa vật lý dữ liệu nghiệp vụ thông thường.
Sử dụng:
deleted_at
deleted_by

Mặc định API chỉ query:
WHERE deleted_at IS NULL


7. MULTI-TENANT READINESS
Ngay cả khi phiên bản đầu chỉ dùng cho một doanh nghiệp, schema nên chuẩn bị:
tenant_id UUID

cho các bảng nghiệp vụ chính.
Có thể triển khai tenant mặc định duy nhất trong MVP.
Điều này giúp sau này hỗ trợ nhiều công ty mà không phải thiết kế lại database.
