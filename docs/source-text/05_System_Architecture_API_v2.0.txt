OMNI CRM – SYSTEM ARCHITECTURE + API SPECIFICATION v2.0
Phạm vi: CRM Core + Sales + Omnichannel + Chatbot + AI + Knowledge Hub + Automation
Tài liệu liên quan: Database Schema v2.0, Screen Architecture v2.0, User Flow v2.0
Mục tiêu: Làm chuẩn kiến trúc kỹ thuật và hợp đồng API để Claude triển khai frontend, backend, integration, messaging, chatbot, AI và RAG theo một kiến trúc thống nhất.

3. KIẾN TRÚC TRIỂN KHAI ĐỀ XUẤT
Trong giai đoạn MVP, không nên triển khai microservices quá sớm.
Khuyến nghị:
Modular Monolith + Background Workers + Connector Services
Cấu trúc:
Frontend
   ↓
Backend Application
   ├ CRM Module
   ├ Sales Module
   ├ Messaging Module
   ├ Chatbot Module
   ├ AI Module
   ├ Knowledge Module
   ├ Automation Module
   └ Admin Module


Background Workers
   ├ Webhook Worker
   ├ Message Delivery Worker
   ├ AI Worker
   ├ Knowledge Indexing Worker
   └ Automation Worker


Lợi ích:
* dễ lập trình;
* dễ debug;
* ít DevOps;
* vẫn giữ domain boundary;
* có thể tách service sau này.

214. NGUYÊN TẮC CUỐI CÙNG
Omni CRM phải bảo đảm:
Một khách hàng có thể chuyển từ Zalo sang WhatsApp, từ Chatbot sang Sales, từ Sales sang CSKH và từ hội thoại sang cơ hội bán hàng mà không mất context.
AI không phải module trang trí.
AI phải được tích hợp vào:
* Customer 360;
* Inbox;
* Pipeline;
* Meeting;
* Lead;
* Quote;
* Knowledge;
* Dashboard.
Chatbot không phải website widget riêng biệt.
Chatbot phải là một actor trong cùng hệ thống Conversation.
API không chỉ phục vụ frontend.
API là xương sống cho:
* Web App;
* Chatbot;
* AI Tools;
* Integration;
* Mobile App tương lai;
* các hệ thống bên ngoài.
Mục tiêu kiến trúc cuối cùng:
Unified Customer Data + Unified Conversation + Unified Sales Process + Shared AI Intelligence + Extensible Integration Layer.
